# Black-Scholes-Pricer-Portfolio-Manager
Black-Scholes Option Pricer &amp; Portfolio Manager est une application interactive développée en Python avec Streamlit et Plotly, conçue pour calculer les prix théoriques d'options (européennes d'achat et de vente) analyser leurs sensibilités (les Greeks : Delta, Gamma, Vega, Theta, Rho) et gérer un portefeuille d'actifs avec une allocation optimisée.
